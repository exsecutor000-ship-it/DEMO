Acerca del portal

Datos abiertos para el desarrollo de América Latina

DataCAF reúne, estandariza y publica libremente los datos que produce y recopila CAF para acelerar la investigación, la política pública y la innovación en la región.

Nuestra misión

Democratizar el acceso al conocimiento regional

Creemos que los datos públicos generan más valor cuando están al alcance de todos: investigadores, gobiernos, periodistas, empresas y ciudadanía.

🔓

Acceso libre

Todos los datasets se publican sin costo, sin registro obligatorio y en formatos abiertos y reutilizables.

🔍

Transparencia

Cada dataset documenta su origen, metodología de recolección y fecha de actualización.

🔗

Interoperabilidad

Publicamos en CSV, JSON, XLSX, SHP y vía API para que los datos se integren fácilmente en cualquier sistema.

Conceptos clave

¿Qué son los datos abiertos?

Datos abiertos son aquellos que cualquier persona puede usar, reutilizar y redistribuir libremente, sujetos como máximo a la exigencia de atribuir su fuente.

1
Completos
Se publican con el mayor nivel de detalle posible, sin restricciones artificiales.
2
Primarios
Provienen directamente de la fuente que recolecta o produce el dato.
3
Oportunos
Se publican y actualizan con la rapidez necesaria para preservar su valor.
4
Accesibles
Disponibles para el mayor número de usuarios y para el mayor rango de propósitos.
5
Procesables
Estructurados razonablemente para permitir su procesamiento automatizado.
6
No discriminatorios
Disponibles para cualquier persona, sin necesidad de registro previo.
7
No propietarios
Disponibles en un formato sobre el cual ninguna entidad tiene control exclusivo.
8
Libres de licencia
No sujetos a derechos de autor, patente o marca registrada que limiten su uso.
Cómo trabajamos

Metodología de publicación

Cada dataset atraviesa un proceso estandarizado antes de llegar al catálogo.

1
Recolección
Los equipos técnicos y organismos colaboradores remiten los datos junto con su documentación de origen.
2
Validación y anonimización
Se verifica calidad, consistencia y se eliminan datos personales o sensibles antes de la publicación.
3
Estandarización
Los datos se normalizan a formatos abiertos (CSV, JSON, XLSX, SHP) con metadatos descriptivos.
4
Publicación
El dataset se incorpora al catálogo, se indexa en la búsqueda y queda disponible vía descarga o API.
5
Actualización periódica
Cada dataset indica su frecuencia de actualización y se revisa según ese calendario.
Para desarrolladores

Cómo usar la API

Consulta el catálogo de forma programática. La API es de solo lectura, pública y no requiere autenticación para uso liviano.

GET /api/v1/datasets Lista todos los datasets del catálogo
GET /api/v1/datasets/{id} Detalle de un dataset específico
GET /api/v1/datasets?category=economia Filtra datasets por categoría
GET /api/v1/categories Lista de categorías disponibles

Ejemplo de solicitud

// JavaScript — fetch fetch('https://api.datacaf.org/v1/datasets?category=energia') .then(res => res.json()) .then(data => console.log(data));

Ejemplo de respuesta

{ "total": 487, "results": [ { "id": 3, "title": "Acceso a Electricidad y Energías Renovables 2010-2023", "category": "energia", "formats": ["csv", "xlsx"], "updated": "2024-06" } ] }

Límite de uso: 1.000 solicitudes por hora por IP para el nivel gratuito. Para volúmenes mayores, contacta al equipo del portal.

Para organismos

¿Tu organización tiene datos que compartir?

Así es el proceso para incorporar un nuevo dataset al catálogo de DataCAF.

1
Contacto inicial
Escribe a datosabiertos@caf.com describiendo el dataset y su relevancia para la región.
2
Revisión técnica
El equipo del portal evalúa formato, calidad y cumplimiento de los principios de datos abiertos.
3
Publicación y mantenimiento
Una vez aprobado, se publica en el catálogo y tu organización queda como fuente oficial del dataset.

Privacidad

DataCAF publica exclusivamente datos agregados y anonimizados. Ningún dataset del catálogo contiene información personal identificable.
